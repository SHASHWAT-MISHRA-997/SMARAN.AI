1. SMARAN CODE (Autonomous Software Engineer)

Location: Top Header Tab `> Code` or Sidebar `Coding Tasks`
Autonomous Agent
📌 Kya Hai (What is it)
  • SMARAN CODE ek specialized **Senior Staff Software Engineer & Systems Architect** agent hai jo aapke local codebase ke sath directly interact karta hai.
  • Chat mode se alag, yeh generic talks nahi karta; yeh pure production-grade architecture, complete syntactically verified code, precise before/after diffs, aur copy-pasteable terminal commands provide karta hai.
  • Aapke open workspace folder ke files aur directories ko inspect karke repo-grounded context inject karta hai.
⚙️ Kaise Use Karna Hai (Steps)
  1. Top bar me **`> Code`** tab par click karein.
  2. Top-left chip par **"Open a folder"** click karke apna project root directory select karein (e.g. your Python or React folder).
  3. Top bar par **"Ask for approval"** toggle on rakhein agar aap file changes review karna chahte hain, ya **"Auto-execute"** karein.
  4. Neeche input bar me prompt type karein ya quick-starter cards (⚡ Inspect, 🚀 Build API, 🧪 Unit Tests, 🐛 Debug) click karein.
🎯 Ushse Kya Hoga (Exact Outcome)
  • AI aapke project files ko analyze karega aur zero-omission complete production code generate karega (koi `// TODO: rest here` nahi).
  • Terminal commands (PowerShell/Bash) provide karega jise run karke aap directly test kar sakte hain.
  • Side-by-side terminal aur coding sessions track hote hain.
🔥 Production Tested Prompts for Testing & Videos
Prompt 1 • Workspace Architecture Inspection
"Inspect this workspace architecture, list all key components, dependencies, database models, and summarize the system design."
Expected Result: AI scans workspace root, outputs clean markdown architecture tree, lists key modules, and provides system diagram breakdown.
Prompt 2 • Enterprise REST API Endpoint
"Design and implement a production-grade FastAPI REST endpoint for user authentication with JWT tokens, bcrypt password hashing, input validation schemas, and rate-limiting."
Expected Result: Complete executable Python code with imports, Pydantic schemas, security dependencies, and unit test snippet.
Prompt 3 • Automated Pytest Test Suite
"Generate a comprehensive pytest test suite covering edge cases, invalid payloads, mock database sessions, and 100% boundary testing for this backend module."
Expected Result: Production pytest suite with fixtures, pytest.mark.parametrize, and assertions.
💡 Video Reel Tip: Screen recorder start karein, folder open karein, starter card "⚡ Inspect Architecture" click karein, aur highlight karein ki kaise local files automatically detect hoti hain.

2. Capabilities (Autonomous Desktop & OS Control)

Location: Settings (`⚙️`) ➔ `Capabilities` & Chat/Voice Input
Native OS Integration
📌 Kya Hai (What is it)
  • SMARAN ka **Native OS Control Engine** natural language se aapke Windows/Linux laptop ko autonomously control karta hai.
  • Yeh mouse clicks, keyboard keystrokes, application launching, screenshot taking, active process listing, aur volume control natively execute karta hai.
  • Safety guard rails enabled hain: Destructive operations (shutdown, file deletion) user confirmation ke bina execute nahi hoti.
⚙️ Kaise Use Karna Hai (Steps)
  1. Settings (`⚙️`) kholein ➔ `Capabilities` tab par jaakar confirm karein ki "Enable Autonomous Computer Use" checked hai.
  2. Chat me ya Voice Speak button daba kar seedhe commands bolein ya type karein (Hindi ya English dono support hain).
  3. Confirmation popup aane par "Confirm & Execute" click karein.
🎯 Ushse Kya Hoga (Exact Outcome)
  • Laptop me specified application khul jaayegi, ya live screenshot capture hokar chat me display hoga.
  • System stats (running apps, PID, CPU/RAM usage) visual cards me aayenge.
🔥 Production Tested Prompts for Testing & Videos
Prompt 1 • Autonomous Desktop Control
"laptop control karo"
Expected Result: SMARAN desktop control engine activate hoga aur current desktop state read karega.
Prompt 2 • Application Launching
"open notepad"
Expected Result: Windows Notepad process background me launch ho jaayegi aur screen par pop-up karegi.
Prompt 3 • Real-Time Screenshot Capture
"take screenshot"
Expected Result: Desktop ka live full-resolution screenshot capture hokar chat card me instantly display hoga.
Prompt 4 • System Telemetry & Process Audit
"what apps are running"
Expected Result: Top active processes ki list with PID, CPU %, and Memory (MB) display hogi.
💡 Video Reel Tip: Voice button dabayein aur bolein "take screenshot" — jab chat me live desktop screenshot aayega, yeh Instagram aur LinkedIn par viewer retention 10x badha deta hai!

4. Automations & Cron (Scheduled Background Workflows)

Location: Sidebar `Scheduled` OR Settings (`⚙️`) ➔ `Automations (Cron)`
Background Daemon Engine
📌 Kya Hai (What is it)
  • Aapke machine par background me recurring AI workflows chalane ke liye built-in scheduler engine.
  • Standard 5-field cron syntax (`* * * * *`) ya interval-based triggers support karta hai.
  • System reports, automated database audits, scraping tasks, aur morning briefings execute karta hai.
⚙️ Kaise Use Karna Hai (Steps)
  1. Sidebar me **`Scheduled`** button par click karein.
  2. "Create New Task" click karein.
  3. Task Title, Target Prompt, aur Cron Expression set karein (e.g., `0 9 * * *` for daily 9 AM).
  4. "Run Now" par click karke immediate test karein.
🎯 Ushse Kya Hoga (Exact Outcome)
  • Task schedule me register ho jaayega aur background thread me continuously track hoga.
  • Execution complete hote hi notification card aur structured log generate hoga.
🔥 Production Tested Prompts for Testing & Videos
Prompt 1 • Automated Morning Health Check
"Check storage disk space, CPU runtime history, and top 5 RAM consuming apps, and format into a morning operational briefing."
Expected Result: Structured hardware & process health report with percentages.
