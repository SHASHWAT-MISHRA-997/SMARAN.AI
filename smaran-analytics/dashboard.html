Installation ids are random values generated on each device. They are not accounts, not people, and are not derived from any hardware identifier, so this page cannot tell you who anyone is — only how many there are and how the software is being used. No conversation, prompt, file or key is ever sent here. Users are shown a notice about this and can switch reporting off; that switch is honoured.
