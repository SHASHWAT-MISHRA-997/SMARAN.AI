01 Quickstart Overview

SMARAN.AI is an autonomous workstation that runs local open-source Large Language Models (DeepSeek R1, Qwen 2.5 Coder, Llama 3.2, etc.) directly on your own GPU/CPU without sending any code, prompts, or conversation history to cloud servers.

Zero Telemetry Guarantee

Your chats, code, embeddings, and audio never leave your local machine. All processing happens through local GGUF quantizations or Ollama runtime.

🖥️ Desktop Autonomous App

Native Windows installer (.exe) with high-performance GPU acceleration, integrated Python backend, and WebUI.

📱 Android Companion

Self-contained mobile APK with local mobile chat, speech synthesis, and local LAN sync with your PC.

⚡ VS Code Extension

Context-aware code completion, inline refactoring, and code generation integrated with your local SMARAN instance.

05 SMARAN Code Studio

SMARAN Code Mode is an isolated development environment inside the desktop app. It allows multi-file repository indexing, automated bug-fixing, terminal execution, and diff viewing.

Isolated Session Context

Code and Design generations never pollute regular Chat sessions. Each workspace retains its own memory, terminal state, and project files.

06 Voice & Speech Engine

SMARAN includes an ultra-fast offline speech pipeline:

  • Whisper Local STT: Transcribes voice input in real-time with zero external cloud round-trips.
  • Kokoro Neural TTS: High-fidelity, emotional voice synthesis running locally on CPU or GPU.

07 Design & Sites Studio

SMARAN Design is a built-in visual generation workspace that lets you create UI components, landing pages, and complete websites using natural language — all processed locally through your AI models.

🎨 AI-Powered Design

Describe any UI in plain language and SMARAN generates production-ready HTML, CSS, and JavaScript with live preview.

🌐 Sites Hub

Browse, manage, and deploy generated websites. Each site is self-contained with its own assets, styles, and scripts.

🔒 Isolated Sessions

Design generations never pollute your regular chat or code sessions. Each design workspace has its own session context and history.

How to Access

Click Design & Sites Studio in the sidebar of the SMARAN desktop app. Use the prompt bar to describe what you want — "Create a dark mode pricing page" — and the design generates in-place with a live preview panel.

08 VS Code Extension

The SMARAN VS Code Extension connects your editor directly to your local SMARAN instance, enabling context-aware AI code completion and inline refactoring without sending code to any cloud service.

⚡ Inline Completions

Get real-time code suggestions from your local model as you type — powered by your own GPU, with zero latency to external servers.

🛠️ Refactoring & Fixes

Select code and ask SMARAN to refactor, explain, optimize, or fix bugs. Results appear as inline diffs with one-click accept.

📂 Workspace Context

The extension indexes your open workspace and feeds relevant file context to the model, so suggestions are aware of your project structure.

Installation

Search "SMARAN AI" in the Visual Studio Marketplace, or run: ext install smaran.smaran-ai from the VS Code command palette. Make sure SMARAN desktop is running on the same machine — the extension connects to localhost:3003 by default.

VS Code Settings (settings.json)json
{
  "smaran.serverUrl": "http://localhost:3003",
  "smaran.autoComplete": true,
  "smaran.model": "auto"
}

09 Android App & Device Pairing

The SMARAN Android application connects to your PC via local Wi-Fi / LAN:

  1. Open SMARAN on your PC and click Host Telemetry / Pair Device in Settings.
  2. Open SMARAN on your Android phone and scan the local network or enter the 4-digit pairing PIN.
  3. Both devices now share synchronized memories, chat history, and can drive local models cooperatively.
