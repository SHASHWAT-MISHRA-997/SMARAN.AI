What it does

Everything in one window,
nothing phoning home.

Assistants usually mean a browser tab and a monthly bill. This one is a program on your computer that happens to be very good at talking.

Talk to it like a person

A real-time voice session with interruption handling — start speaking and it stops to listen, the way a conversation actually works. Pick a voice and a persona; it answers in the language you set.

It can see

Point the camera at a thing, or drop in a screenshot. Vision models read what is in front of them.

Gesture mode

Hands in the air, Stark-style. Pinch, swipe and hold to drive the interface without touching anything.

Webcam required

Your own documents

Hand it PDFs, notes, spreadsheets. It answers from those, and says so when the answer is not in them rather than inventing one.

Your phone and your PC, paired

Scan a QR code once. After that the conversation follows you between devices, and either one can drive the other — speak to your phone, and your computer does the work.

Locked like a phone

A PIN on startup, with the attempt limits and lockouts you would expect. Your history is not one click away for whoever walks past.

Real hardware readings

CPU, memory, GPU and battery from the actual machine — including whether it is charging — not a decorative animation.

Sixty-three models, one hub

Download local models and keep them forever, or plug in a key for a cloud provider when you want the big ones. The hub is honest about the difference between catalogued, downloaded and actually running.

Getting started

Three steps, then it is yours.

  1. 01

    Install it

    Run the installer. Python and the app are bundled, so there is no environment to prepare. To run models locally you also need Ollama, which is a separate free install.

  2. 02

    Pick a model

    Open the Model Hub and download one. A small one runs on almost anything; a bigger one wants more memory. It tells you which is which.

  3. 03

    Start talking

    Type, or press Speak. If you want it on your phone too, scan the pairing code.

Privacy

The honest version.

Most assistants say "we care about your privacy" and then send every word you type to a server. Here is what this one actually does.

✓ Stays on your machine

  • Everything you type or say
  • Your files and what is in them
  • Your conversation history
  • Any API keys you enter
  • Camera and microphone input

↗ Leaves only if you choose it

  • Cloud models — only after you add a key, and only the message you send
  • Web search — only when you switch it on
  • A counter of installs and launches, with a random id and no content, which you can turn off in Settings

The usage counter exists so the number of people using this is a fact rather than a guess. It carries an install id, the platform and a version number. It never carries anything you wrote. The switch that turns it off genuinely turns it off.

Questions

Reasonable things to ask.

Is it really free, or free-for-now?

Free. There is no paid tier, no usage cap and no card anywhere in the app. A local model you download runs on your own hardware, so there is nothing to bill you for. If you connect a cloud provider, that provider bills you directly — nothing to do with this app.

Do I need internet?

To download the app, Ollama and a model, yes. After that a local model works with the network off. Web search and cloud models obviously need a connection.

What hardware do I need?

It depends on the model, and the hub is specific about it. Across the 63 models in the catalogue the stated memory requirement runs from 4 GB to 512 GB, and 18 of them ask for 8 GB or less. Every entry shows its requirement before you download it.

Why does Windows warn me about the installer?

Because it is not code-signed. A signing certificate is a yearly cost, and this project does not charge anyone. The warning is Windows saying it has not seen this publisher before — not that it found anything wrong. You can check the file on VirusTotal, or build it yourself from the source.

Can the phone app work when my PC is off?

Yes. The phone app is a working assistant on its own. Pairing adds shared history and lets each device drive the other, but it is not required.

Where is my data stored?

In your own user folder on your own drive. Nothing is uploaded, and there is no account holding it. Deleting the app's data folder deletes it.

Is the source available?

The code is on GitHub. Note that there is no licence file yet, so it is not correct to call it open source — read it, build it, but the owner has not granted redistribution rights.
