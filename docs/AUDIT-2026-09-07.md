# SMARAN.AI audit and local update — 7 September 2026

The source and bundled web UI are updated to **2.10.34**. The packaged VS Code
extension is **2.20.1**, and the CLI wheel is **2.10.34**. This work builds on
`1370359` (release 2.10.33). These are local changes and artifacts; no commit,
push, marketplace publication or production website deployment was performed.

updated in place with the signed release APK. Windows installer testing uses a
separate payload and data directory under `.cache/audit/`.

## Fixed findings

| Area | Reproduced issue and resulting behavior |
| --- | --- |
| Account startup | Startup created a public default administrator password and could reset a locked account to it. Removed both startup credential writes. A fresh database has no seeded administrator. |
| PIN gate | Failed or malformed lock-status responses opened the workspace. They now keep it hidden, show an unavailable state, and offer a retry. |
| Settings responsiveness | Opening Settings ran the CUDA/Whisper probe on the API event loop. Subsequent screens stalled. Both GPU status and installation routes now run their synchronous work in FastAPI's worker pool. |
| Model Hub | App and Sidebar rendered the same modal simultaneously. Two headings and two sets of controls were present, and the sidebar copy lacked the app's model-selection callback. Only the owning component now renders the modal; a live regression confirms choosing an installed model changes the next chat request. |
| API and static routing | The SPA catch-all preceded model-storage/engine routes and the upload mount, returning HTML for their requests. It now registers last, returns 404 for unknown API/assets, and checks resolved file ancestry instead of a string prefix. Synchronous model storage/engine work also uses the worker pool. |
| Unexpected server errors | The global handler returned raw exception text to clients. It now returns a generic failure while preserving details in the local log. |
| Desktop intents | Negated requests and conversational mentions could toggle mute. Explicit commands are required; negative startup commands resolve to disabling startup. The packaged desktop permission handler now also checks the exact local origin before granting media access. |
| Audio controls | Volume used keyboard character codes and reported a requested value without measuring it. Windows Core Audio now sets and reads back the value. Explicit unmute sets mute to false instead of toggling it. |
| Clipboard | Clipboard text was interpolated into PowerShell source. It now travels through UTF-8 stdin, preserving quotes, Unicode and literal shell-like text, and subprocess failures are reported. |
| Extension registry | Registry failures appeared as empty success, stale MCP entries survived an empty response, and zero running extensions showed “all running.” Errors, empty views and actual running counts now have distinct states. |
| Legacy plugin modal | An unused modal contained a syntax error and invented fallback plugin states. Its old import now resolves to the maintained ExtensionsHub. |
| Accessibility | Reply-language selects lacked accessible names; telemetry status had inadequate contrast. Added names and corrected status colors. Site, Settings and Model Hub close buttons and the terminal field now have accessible names. Terminal help text was also brightened after screenshot inspection. |
| Telemetry labels | Unmeasured CPU, network and memory information used misleading success/device labels. Missing measurements now say unavailable or identify browser estimates. |
| Frontend maintenance | Removed unused imports, bindings and dead display components; corrected escapes and redundant spreads; removed a text-repair regex that could never match. Final source lint has zero diagnostics. |
| Conversation isolation | Existing chat, message, rename, clear, vision and privacy routes could reassign a session to whoever supplied its ID. They now scope lookups to the authenticated owner; a two-account API test covers reads, writes and deletion. |
| Offline speech | Kokoro TTS and faster-whisper were exercised together on a known sentence, with an exact transcript on CPU and NVIDIA CUDA. The frozen Windows app starts in an isolated data directory and publishes its runtime port; WebView2 media permission logging is active. |
| Android media and voice | Capacitor's WebChromeClient now delegates runtime permission prompts only for the app's exact origin and audio/video resources. The native SpeechRecognition proxy is wrapped without Promise assimilation, so Android dictation/Speak starts the device recognizer with its installed `en-GB` language pack. Wake listening pauses while explicit dictation owns the microphone. Auto Router has a safe-area close button plus Android hardware Back handling, and the performance panel is not mounted on phone UAs in either orientation. Origin/media tests pass; debug APK 2.10.34 was rebuilt and installed on the authorized CPH2573 (Android 16). |
| Mobile interaction follow-up | Android dictation now keeps its listener alive briefly after the system signals speech end, so final words are delivered before the field closes. A silent turn reports no speech rather than an unavailable input. Android Back was verified to close the tools sheet and model picker while keeping the app foregrounded. Landscape phones show the complete one-row composer toolbar, while portrait keeps its compact tools sheet. The mobile Settings screen no longer offers the desktop-only sidebar-position control. |
| Frontend dependencies | Fixed the reported dependency advisories with compatible updates and an xcode-scoped uuid override. Final npm audit reports zero vulnerabilities. xcode UUID generation was exercised with 1,000 unique valid IDs. |
| Web bundle | Split Three/VRM and chart dependencies from the approximately 1.91 MB main entry. The main entry is approximately 841 KB; the build no longer reports an oversized chunk. |
| Python compatibility | Replaced deprecated Pydantic configuration/validators, SQLAlchemy declarative imports and FastAPI event decorators. Fresh database tables are created before migrations. Intentionally disabled Qdrant no longer emits an initialization warning. |
| NVIDIA dependency | Replaced the deprecated `pynvml` distribution requirement with `nvidia-ml-py`. The official binding was installed only inside the audit folder and successfully read the GPU count without warnings using an isolated import path. |
| Extension read-only policy | Browser click/type actions bypassed read-only mode. They are now treated as mutations and follow the approval policy. |
| Extension file edits | Parser trimming and string replacement expanded or lost literal source text. Whitespace and replacement metacharacters now survive. Proposed file diffs are available before approval, and an edit is refused if the file changes during review. |
| Extension workspace boundary | New nested paths under an outward junction could evade path confinement. The nearest existing ancestor is now resolved before checking the boundary. Search checks resolved file paths as well. |
| Extension undo | History used relative paths across projects and could restore a file deliberately deleted after an agent edit. History now identifies absolute targets and refuses changed/deleted files. |
| Extension transport | Closing the browser could leave pending promises unresolved. Close/send failures now reject requests and clear their timers; browser text lookup preserves literal dollar signs. Successful tool replies no longer leak their wrapper tags. |
| VSIX packaging | `--no-dependencies` silently omitted `ws` even though the ignore file allowed it. Removed that flag and inspected the resulting archive for the runtime files. |
| Version metadata | Synchronized application versions and extension lockfile metadata. CLI packaging now reads `smaran_cli.__version__`, avoiding a separate stale package version. Removed the obsolete version from the README heading. |

FastAPI's lifecycle migration follows its [lifespan documentation](https://fastapi.tiangolo.com/advanced/events/).
The NVIDIA requirement follows the package maintainers' [deprecation notice](https://pypi.org/project/pynvml/)
and [official binding](https://pypi.org/project/nvidia-ml-py/).
