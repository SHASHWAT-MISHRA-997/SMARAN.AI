## The Android work, and what must not be undone

`frontend/android/app/src/main/java/ai/smaran/app/`:

- `SmaranDevice.java` — Capacitor plugin: open apps, YouTube, music, URLs,
  picture-in-picture, start/stop the listening service.
- `SmaranVoiceService.java` — foreground service, microphone type, ongoing
  notification with a Stop action. Makes a second command possible.
- `DeviceActions.java` — command patterns and execution, **shared** by the
  plugin and the service so they cannot disagree.
- `SmaranSpeech.java` — recognition and TTS for the on-screen case.

Hard-won details:

- **`getContext()` on a plugin is the Application context.** An activity started
  from it is a background launch, restricted since Android 10; the symptom is
  success reported and nothing appearing. Launch from the Activity or the
  foreground service.
- **`resolveActivity` lies since Android 11.** It answers through the
  package-visibility filter and returned null for YouTube on a phone that has
  it. Try the launch and catch the failure.
- **The manifest deliberately avoids `QUERY_ALL_PACKAGES`.** App discovery uses
  a scoped MAIN/LAUNCHER `<queries>` entry.
- **`handleOnPause` must not tear down recognition in picture-in-picture** — the
  activity pauses when it floats, and it used to go deaf at that moment.
- **Only one recogniser at a time.** Two competing for the microphone is what
  Codex fixed; the ownership rule is Activity-visible wins.
- **`stop`, `cancel` and "band karo" are absent from the refusal lists on
  purpose**, in both the JS and Java detectors — "awaz band karo" is a real
  instruction. Tests catch this; do not tidy them back in.

## Environment notes that save time

- Windows 11, `bash` is Git Bash. **Nested quoting into `wsl bash -c '...'`
  mangles `awk` and `$`** — write a script file and run `wsl bash /mnt/c/...`.
  Git Bash rewrites `/mnt/c/...` arguments; prefix with `MSYS_NO_PATHCONV=1`.
- **A heredoc piped to a `python` that is not on PATH hangs on stdin.** Windows
  has no `python`; use
  `/c/Users/shash/AppData/Local/Programs/Python/Python314/python`, or `python3`
  inside WSL.
- adb is at `/c/Asdk/platform-tools`; the device is `8f807260`.
  **`uiautomator dump` often returns "null root node"** because the WebView does
  not expose its tree, so coordinate taps are frequently the only option — and
  taps near the bottom trigger gesture navigation and open recents or search.
  Screenshot after every step; never chain blind taps.
- The app's readiness check uses `urllib`, which honours `HTTP_PROXY`. Set
  `NO_PROXY=127.0.0.1,localhost,::1` or you will route a loopback health check
  through a dead proxy and wrongly conclude the app fails offline.
