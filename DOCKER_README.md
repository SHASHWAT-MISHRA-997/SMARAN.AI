---

## 💻 Operating System Installation & Startup Guide

### 1. 🪟 Windows Users
1. Double-click **`SMARAN.AI.exe`** (or `launch_app.bat`).
2. Open your browser at **`http://localhost:3003`**.

---

### 2. 🍏 macOS & 🐧 Linux Users
1. Open Terminal in the unzipped folder.
2. Run:
   ```bash
   chmod +x launch_app.sh
   ./launch_app.sh
   ```
3. Open your browser at **`http://localhost:3003`**.

---

### 3. 📱 Mobile Users (Android & iPhone / iPad)
1. Ensure your phone and host PC/laptop are on the **same local Wi-Fi network**.
2. Find your host PC's IP address (e.g., `192.168.1.5`).
3. Open Chrome or Safari on your phone and go to:
   ```
   http://<YOUR_HOST_PC_IP>:3003
   ```
4. **Install as Native Mobile App (PWA)**:
   - **Android**: Tap the 3 dots menu in Chrome → select **"Add to Home Screen"** or **"Install App"**.
   - **iPhone/iPad**: Tap the Share button in Safari → select **"Add to Home Screen"**.
